📖 GETTING STARTED
═══════════════════════════════════════════════════════════════════════════════

1. First Time? Start with:
   ├─ README.md                    ← Feature overview & system requirements
   └─ QUICKSTART.md                ← 5-minute setup guide


2. Build & Run the App:
   ├─ chmod +x flux-terminal.sh
   ├─ ./flux-terminal.sh build
   └─ open build/Build/Products/Debug/Flux.app


3. Configure on First Launch:
   ├─ Settings → Wine Directory: /opt/homebrew/bin/wine  (base Wine; wine64 is not present on Apple Silicon)
   ├─ Settings → GPTK Path: /opt/gptk (optional, only if enabled)
   ├─ Settings → Verify Installation (Wine always required)
   ├─ Settings → Run Wine Smoke Test (prefix init + cmd execution)
   └─ Note: Windows ARM64 executables are not supported (Windows x86/x64 only)


4. Detect and Launch Games:
   ├─ Games → Refresh (scan Steam library)
   ├─ Select a game
   ├─ Click Launch
   └─ Watch Logs for real-time output

✨ KEY FEATURES
═══════════════════════════════════════════════════════════════════════════════

✅ Automatic Steam Game Detection
   └─ Scans your Steam library and finds installed games

✅ Game Launching
   └─ Run Windows games with Wine (GPTK optional)

✅ Dashboard + Recents
   └─ Quick access to recent launches

✅ Wine Prefix Management
   └─ Create and manage multiple prefixes

✅ Real-Time Logging
   └─ Monitor game output in real-time

✅ Dependency Management
   └─ Verify and manage DirectX DLLs

✅ DRM Detection
   └─ Warns about DRM-protected games

✅ System Information
   └─ Displays Wine, GPTK (if enabled), and Metal device info

✅ Clean Minimal UI
   └─ No gamer aesthetics, utility-first design

Build and run:
    $ cd /Users/efealibel/OpenFlux
    $ ./flux-terminal.sh build
    $ open build/Build/Products/Debug/Flux.app

Test Wine installation (base Wine binary on Apple Silicon):
    $ /opt/homebrew/bin/wine --version

Check GPTK:
    $ ls /opt/gptk/

View system GPU:
    $ system_profiler SPDisplaysDataType

💡 TIPS
═══════════════════════════════════════════════════════════════════════════════

• Always check Logs tab for real-time game output
• Settings show detected Wine, GPTK (optional), and Metal versions
