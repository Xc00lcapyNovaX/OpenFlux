## 🎨 Hex Color Picker

### What It Does
- ✅ Enter hex codes: #3399FF
- ✅ Adjust with RGB sliders (0-255)
- ✅ See real-time color preview
- ✅ Copy hex to clipboard
- ✅ Convert hex ↔ RGB instantly

### How to Access
1. Settings (⚙️)
2. Appearance section
3. Click "Edit Colors"
4. Color picker opens!

### Input Methods
| Method | Example |
|--------|---------|
| Hex | #3399FF |
| Red Slider | Drag 0-255 |
| Green Slider | Drag 0-255 |
| Blue Slider | Drag 0-255 |
| Text Input | R: 51, G: 153, B: 255 |
