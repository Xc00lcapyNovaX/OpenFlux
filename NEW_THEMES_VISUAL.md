## Using the Hex Picker

### To Explore Space Black Tones
1. Go to Settings → Edit Colors
2. Enter: `#050508` for darkest background
3. Try: `#80CCFF` for primary blue
4. Experiment with variations

### To Create Blue Variants
1. Start with: `#4DB2FF` (primary blue)
2. Lighten: `#66CCFF` (lighter variant)
3. Darken: `#3399CC` (darker variant)

### To Match Silver Tones
1. Use: `#262629` for gray background
2. Try: `#4D99E6` for blue primary
3. Accent: `#99D9FF` for light highlights
